Gemini AI DevOps Assistant
Project Overview
Developed a web-based AI assistant that uses Google’s Gemini API to answer DevOps-related questions. The application is built with Python and Flask and provides a simple web interface for users to submit questions and receive AI-generated responses.
Key Features
* Integrated Google Gemini API for AI-powered DevOps question answering.
* Developed a web interface using HTML and CSS.
* Implemented Flask routes to handle user requests and display AI-generated responses.
* Configured API key access through environment variables.
Technologies Used
* Python
* Flask
* Google Gemini API
* HTML
* CSS
* AWS EC2
